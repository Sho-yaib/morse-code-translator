# Morse Code Translator

A cross-platform command-line Morse Code Translator developed in C.

## Features

- English to Morse translation
- Morse to English translation
- 54-character Morse table
- Sound feedback
- Visual feedback
- Translation history
- Replay functionality
- Adjustable translation speed
- Clipboard integration
- Input validation
- Cross-platform support

## Technologies

- C
- C99 or higher
- GCC / MinGW / MSVC / Clang

## How to Run

Compile the program:

gcc Morse_Code_Translator.c -o morse

Run:

./morse
